第二章：跟着拼一次，到达 (3,2)

对照目标坐标，手算系数

这是一道自编示范。我们想找到系数 a,b，让 au+bv=(3,2)。用刚才的结果 (a+b,b) 与目标比较：

{a+b=3,b=2.

第二个坐标直接告诉我们 b=2。把它放回第一行，得到 a+2=3，所以 a=1。于是答案是 u+2v=(3,2)。再把两个坐标分别算一遍，就能确认它确实到达目标。

用代码核对刚才的结果

下面的 Python 代码只核对这道示范。即使不运行，也可以顺着缩进读：函数里逐个计算两个坐标，再把它们组成结果。

def combine(a, u, b, v):
    coordinates = []
    for i in range(len(u)):
        coordinates.append(a * u[i] + b * v[i])
    return tuple(coordinates)

u = (1, 0)
v = (1, 1)
result = combine(1, u, 2, v)
assert result == (3, 2)
print(result)
