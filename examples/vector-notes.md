# 用两支向量，拼出一次移动

## 第一章：先想象你在方格纸上走路

### 用坐标记下一次移动

从原点出发，向右走一步，可以记成向量 $u=(1,0)$。括号里的第一个数表示向右移动多少，第二个数表示向上移动多少；负数就表示向相反方向移动。另一个向量 $v=(1,1)$ 表示向右、向上各走一步。

把两次移动接在一起，就是向量相加。每个方向分别合计，所以 $u+v=(1+1,0+1)=(2,1)$。而 $2u=(2,0)$ 表示把 $u$ 的移动放大到两倍。这里的“倍数”不一定是整数：$0.5u$ 是原来的一半，$-u$ 则把方向反过来。

### 给两支向量选倍数，再组合

现在允许给 $u$、$v$ 各选一个实数倍数，再相加。这就是它们的**线性组合**：

$$
a u+b v=a(1,0)+b(1,1)=(a+b,b).
$$

$a$ 和 $b$ 叫作系数，也就是你给两支向量各选的倍数。上式的最后一步只是分别合计两个坐标，没有额外的运算规则。

这两支向量能拼出平面上的任何一次移动。稍后会看到，把它们并排写进矩阵后，<a id="mention-rank" class="term" href="#term-rank">矩阵的秩</a>为 $2$，意思是这里有两个彼此独立的方向。如果“秩”还是陌生词，可以点开新标签页里的小课堂，读完关闭它或切回正文，这里的位置不会动；先继续看怎么算也完全可以。

## 第二章：跟着拼一次，到达 $(3,2)$

### 对照目标坐标，手算系数

这是一道自编示范。我们想找到系数 $a,b$，让 $a u+b v=(3,2)$。用刚才的结果 $(a+b,b)$ 与目标比较：

$$
\begin{cases}
a+b=3,\\
b=2.
\end{cases}
$$

第二个坐标直接告诉我们 $b=2$。把它放回第一行，得到 $a+2=3$，所以 $a=1$。于是答案是 $u+2v=(3,2)$。再把两个坐标分别算一遍，就能确认它确实到达目标。

### 用代码核对刚才的结果

下面的 Python 代码只核对这道示范。即使不运行，也可以顺着缩进读：函数里逐个计算两个坐标，再把它们组成结果。

```python
def combine(a, u, b, v):
    coordinates = []
    for i in range(len(u)):
        coordinates.append(a * u[i] + b * v[i])
    return tuple(coordinates)

u = (1, 0)
v = (1, 1)
result = combine(1, u, 2, v)
assert result == (3, 2)
print(result)
```

### 动手拼出 $(2,-1)$

仍然用 $u=(1,0)$ 和 $v=(1,1)$。请找出 $a,b$，使 $a u+b v=(2,-1)$。可以先在纸上写出两个坐标分别需要满足什么条件，再核对答案。

<details class="hint" markdown="1">
<summary>需要时，看一点提示</summary>

先看第二个坐标。$u$ 对上下移动没有贡献，所以这个坐标完全由 $b v$ 决定。负系数是允许的，它表示把向量的方向反过来。

</details>

<details class="solution" markdown="1">
<summary>展开答案与过程</summary>

由于 $a u+b v=(a+b,b)$，我们需要：

$$
\begin{cases}
a+b=2,\\
b=-1.
\end{cases}
$$

先得到 $b=-1$，再由 $a-1=2$ 得到 $a=3$。因此 $3u-v=(3,0)-(1,1)=(2,-1)$。

容易混淆的是 $-v$：它的两个坐标都要变号，得到 $(-1,-1)$，不能只把第二个坐标变号。

</details>

</section>

回头看这两次计算，我们都是先从目标的第二个坐标找到 $b$，再调整 $a$。如果两支向量始终沿同一条直线，这个办法就不能到达任意位置了。<a id="mention-rank-again" class="term" href="#term-rank">矩阵的秩</a>正好帮我们描述这种区别。

<section id="term-rank" class="prerequisite" markdown="1">

### 小课堂：秩在数什么

先把“矩阵”看成一个排整齐的数字表。把 $u=(1,0)$ 和 $v=(1,1)$ 作为两列并排写，就得到：

$$
A=\begin{pmatrix}1&1\\0&1\end{pmatrix}.
$$

矩阵的**秩**可以理解为：这些列向量提供了几个彼此独立的方向。严格地说，它是列向量中最多能选出的线性无关向量的个数。“线性无关”表示，只有把所有系数都取成 $0$，它们的线性组合才会得到零向量；只要能找到一组不全为 $0$ 的系数却合成零向量，它们就是线性相关的。

在这里，$u$ 只向右，$v$ 却还有向上的分量，所以 $v$ 无法通过把 $u$ 乘一个数得到。再具体检查一下：如果 $a u+b v=(0,0)$，第二个坐标迫使 $b=0$，第一个坐标再迫使 $a=0$。两列确实线性无关，因此 $A$ 的秩为 $2$。

换一组小例子：若两列是 $(1,0)$ 和 $(2,0)$，第二列只是第一列的两倍。无论怎样组合，都只能在水平线上移动。这时最多只能选出一支线性无关的向量，所以秩为 $1$。如果所有列都是零向量，秩就是 $0$。

对这节内容，只要记住：秩数的是独立方向的个数，并不是非零数字的个数。主文里的两支向量提供两个独立方向，所以能拼出平面上任意向量。

</section>
