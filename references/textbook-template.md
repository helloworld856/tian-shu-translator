# 自学读物写作母版

这是写作与交互示意，不是每节要填满的课堂教案。方括号是明确占位提示；制作时替换为核对过的内容，删除说明文字与不适用的块。没有真实课件时，不把本模板当作已完成课程导出。

母稿用自然段带着读者向前走，每个顶层 `##`（h2）对应一个独立章节 HTML，`###`（h3）及以下是章内内容，不单独拆文件。章节标题必须放在母稿顶层，不能放进 `section.exercise`、`details` 等容器。`###` 用于本章自然子话题，将进入本章小节目录；一道练习本身构成小节时也可用 `###`，题内细节与答案内标题则用 `####` 及以下，避免泄露在小节目录中。按实际话题起自然章名，只保留需要的小标题，不机械拆段或凑模板。可以从一个小问题进入，解释直觉，再把定义、符号和推理嵌进讲解。遇到图或公式就在相关位置解释，不必另起固定栏目。比喻点到为止，说明它在哪一步不再适用。

以下框架可作为 Markdown 母稿起点，保存到课程项目的 `output/课程名/_work/课程.md`；提取 JSON、页面 PNG、素材、覆盖台账和进度也全部保存在这个 `_work/` 中。编译器不复制母稿。制作与编译命令统一见 [README：课程制作](../README.md#课程制作)，路径基准与技能入口一致：当前目录是课程项目，脚本与依赖从实际加载的 `SKILL.md` 所在目录定位。

输出目录内的 `index.html` 只显示课程标题和各章索引列表，不放导言、章节正文、全课侧栏或小课堂。各章依次生成到 `chapters/chapter-01.html`、`chapter-02.html` 等；索引中的章节链接使用 `target="_blank" rel="noopener noreferrer"`，在新标签页打开，索引页 URL 与滚动位置始终保留。编译器自动生成索引，无需手写 `[TOC]`。

章节正文位于视口中央，左侧留白放小字号的本章小节目录，只链接本章 `h3` 的本页锚点，平滑滚动并随阅读高亮，不列全课章节；窄屏改为顶部折叠目录。页尾提供“上一章／课程目录／下一章”，上一章／下一章在当前标签页切章，正文中显式跨章引用也可在当前标签页打开。母稿 `#` 课程标题后、第一个 `##` 前的导言由编译器完整移到第一章思维导图后（旧无图母稿仍在标题后），索引页不显示。没有任何 `##` 的短母稿兼容为名为“正文”的单章，`index.html` 仍为纯索引。

正文首次引用前置术语时设独立锚点，同一术语的再次引用换用新的提及锚点，仍指向同一个小课堂说明块。编译后，小课堂从正文抽取到课程文件夹内的 `lessons/`。所有页面内联公式、图片、样式和脚本；禁用 JavaScript 后仍可通过原生链接切换章节、跳转章内锚点和打开小课堂。正式只交付这一个课程文件夹，移动或转发整个文件夹即可，阅读不依赖外部路径。正式回复只给课程文件夹路径或链接和一句“打开里面的 `index.html`”，不分别列出各章节、小课堂和台账文件。

## 母稿语法

- 公式用 `$...$` 和 `$$...$$`，编译为 MathML；查看关键公式的实际渲染，不能把裸露 LaTeX 视为完成。
- Markdown 支持 `extra`、`toc`、`sane_lists`。需要解析 Markdown 的 HTML 容器加 `markdown="1"`，块内留空行；代码使用 fenced code block 并保留缩进。所有 HTML `id` 在整篇母稿中唯一。
- 题目用 `section.exercise` 容纳完整题干和附图；提示用 `details.hint`，完整答案用 `details.solution`，均不加 `open`。提示层数按需要设置，不在题干泄露结果；每题保留完整解析。
- 术语入口使用 `class="term" href="#term-key"`，共用 `section.prerequisite` 说明块。编译器负责抽取小课堂、改写链接和新标签页属性；作者不必写 `target` 或返回链接，旧母稿的 `return-link` 会被忽略。
- 本地图片路径相对输入母稿所在目录，如 `_work/课程.md` 引用 `images/原图.png`。必要图片先保存到 `_work/` 并核对，不引用远程图片、CDN、在线字体或脚本。内联 SVG 的 marker、渐变等定义须与使用它的图位于同一个输出页面，不能跨章节或小课堂引用。

## 章节思维导图

新制作的每个教学章节在顶层 `##` 后直接放一个 `chapter-map` 代码块，中间只留空白或注释；一章一图，不能放进练习、折叠块或小课堂。先呈现本章少量核心知识点及其关系，再进入导言或正文。作者明确写出关系，不能从 `###` 标题猜测；教学步骤可用“递进”，不要误画成因果。只选本章实际需要的关系，无需把并列、包含、递进都塞进同一张图。

```chapter-map
{"nodes":[{"id":"operations","label":"向量运算"},{"id":"addition","label":"向量相加"},{"id":"scaling","label":"数乘"}],"edges":[{"from":"operations","to":"addition","relation":"包含"},{"from":"operations","to":"scaling","relation":"包含"},{"from":"addition","to":"scaling","relation":"并列"}]}
```

`nodes` 中每项有图内唯一的 `id` 和简短通俗的 `label`；`edges` 用 `from`、`to` 引用节点 ID，`relation` 写清连线含义。建议 3–6 个节点，允许 1–8 个节点、0–12 条边；`id` 最长 48 字符、`label` 最长 24 字符、`relation` 最长 12 字符，均非空且不含控制字符。不重复节点或连线，不引用不存在的节点，不支持环或自连接；关系复杂时简化为核心内容。标签不堆公式或长段，细节留在正文；图中不得提前给出练习提示、计算结果或答案。关系精确写“并列”时，节点同层、连线无箭头；其他关系由 `from` 指向 `to`，关系文字始终可见。

编译后是内联静态 SVG，位于章节 `h1` 下、导言和正文前，不依赖网络或 JavaScript。图注不使用 `h3`，不会进入本章小节目录；索引页仍只列章节，小课堂和仅说明资料来源的非教学章节无需加图。旧的无图母稿继续兼容编译，教学章节一章一图是新稿的制作要求。上图只是语法示意，制作时按本章真实内容重写。
