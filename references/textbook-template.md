# 自学读物写作母版

这是写作与交互示意，不是每节要填满的课堂教案。方括号是明确占位提示；制作时替换为核对过的内容，删除说明文字与不适用的块。没有真实课件时，不把本模板当作已完成课程导出。

母稿用自然段带着读者向前走，每个顶层 `##`（h2）对应一个独立章节 HTML，`###`（h3）及以下是章内内容，不单独拆文件。章节标题必须放在母稿顶层，不能放进 `section.exercise`、`details` 等容器；题目与说明块内部标题用 `###` 或更低级别。按实际话题起自然章名，只保留需要的小标题，不机械拆段或凑模板。可以从一个小问题进入，解释直觉，再把定义、符号和推理嵌进讲解。遇到图或公式就在相关位置解释，不必另起固定栏目。比喻点到为止，说明它在哪一步不再适用。

以下框架可作为 Markdown 母稿起点，保存到课程项目的 `output/课程名/_work/课程.md`；提取 JSON、页面 PNG、素材、覆盖台账和进度也全部保存在这个 `_work/` 中。编译器不复制母稿。制作与编译命令统一见 [README：课程制作](../README.md#课程制作)，路径基准与技能入口一致：当前目录是课程项目，脚本与依赖从实际加载的 `SKILL.md` 所在目录定位。

输出目录内的 `index.html` 是课程目录／导言页，保留第一个章节前的内容；各章依次生成到 `chapters/chapter-01.html`、`chapter-02.html` 等。编译器自动生成目录，无需手写 `[TOC]`。章节页左侧列出全课章节链接，点击会在当前标签页切换章节；当前章的小节通过本页原生锚点平滑滚动，并在阅读时高亮当前位置。手机端导航折叠，页尾提供“上一章／课程目录／下一章”，独立小课堂不进入主索引。

正文首次引用前置术语时设独立锚点，同一术语的再次引用换用新的提及锚点，仍指向同一个小课堂说明块。编译后，小课堂从正文抽取到课程文件夹内的 `lessons/`。所有页面内联公式、图片、样式和脚本；禁用 JavaScript 后仍可通过原生链接切换章节、跳转章内锚点和打开小课堂。正式只交付这一个课程文件夹，移动或转发整个文件夹即可，阅读不依赖外部路径。正式回复只给课程文件夹路径或链接和一句“打开里面的 `index.html`”，不分别列出各章节、小课堂和台账文件。

## 母稿语法

- 公式用 `$...$` 和 `$$...$$`，编译为 MathML；查看关键公式的实际渲染，不能把裸露 LaTeX 视为完成。
- Markdown 支持 `extra`、`toc`、`sane_lists`。需要解析 Markdown 的 HTML 容器加 `markdown="1"`，块内留空行；代码使用 fenced code block 并保留缩进。所有 `id` 在整篇母稿中唯一。
- 题目用 `section.exercise` 容纳完整题干和附图；提示用 `details.hint`，完整答案用 `details.solution`，均不加 `open`。提示层数按需要设置，不在题干泄露结果；每题保留完整解析。
- 术语入口使用 `class="term" href="#term-key"`，共用 `section.prerequisite` 说明块。编译器负责抽取小课堂、改写链接和新标签页属性；作者不必写 `target` 或返回链接，旧母稿的 `return-link` 会被忽略。
- 本地图片路径相对输入母稿所在目录，如 `_work/课程.md` 引用 `images/原图.png`。必要图片先保存到 `_work/` 并核对，不引用远程图片、CDN、在线字体或脚本。内联 SVG 的 marker、渐变等定义须与使用它的图位于同一个输出页面，不能跨章节或小课堂引用。
